# 🎓 Educational Platform

## 📌 Overview

**Educational Platform** is a web-based project developed as a team assignment during our **first year in the Faculty of Computer Science**. The project reflects our early experience in building front-end web applications and collaborating as a team.

The platform is designed to provide educational content in different subjects, offering a simple and organized interface for students to explore materials such as mathematics and biology.

---

## 🚀 Features

* 📚 Multiple educational sections (Mathematics, Biology, etc.)
* 🖥️ Simple and user-friendly interface
* 🔐 User authentication (Login & Register صفحات)
* 📩 Contact page for communication
* 🧾 Subscription page
* 🎨 Styled using CSS for better user experience
